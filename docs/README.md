# `docs/` — tài liệu

| File | Nội dung |
|---|---|
| `ARCHITECTURE.md` | kiến trúc: tiến trình, lớp, thread, vòng đời, một chu kỳ fixture đi qua các module, bất biến an toàn |
| `FEATURES.md` | tính năng và hành vi chi tiết (chu kỳ fixture, End Effector, tray, chạy/dừng robot, UO[3], thủ công, so với RCS cũ) |
| `robot_bridge_guide.md` / `.ipynb` | giao thức bridge robot (TCP/JSON → FRRJIf), mã lỗi, client mẫu |
| `ui_preview/` | ảnh chụp giao diện (bản lưu; ảnh mới nhất do `devtools/ui_preview` sinh ra) |

README của từng module nằm cạnh mã: `MainRCS/rcs2/<module>/README.md`; bản đồ tổng và bảng "muốn sửa X thì vào đâu": `MainRCS/README.md`.
